Help us reproduce the issue

Include your device model, OS version, app version and build number, steps, expected result and actual result. Redacted screenshots can help. Do not send passwords, session links, private scores or student information. TestFlight testers can also use the feedback option in TestFlight.

Get started

In the app, choose Create from template → Staff paper, enter a title and create a score to try reading and annotations without an account or private file. You can also import an authorized PDF through the system Files picker.

Save and recover

Wait for saving to finish, return to the library and reopen the score to confirm your annotations. Export important scores and complete backups before beta updates. Try recovery with test data first. If something goes wrong, preserve original files and backups instead of repeatedly overwriting them.

Permissions and beta access

Photography, recording, pitch tools, nearby sessions and reminders need permissions only when you choose those features; manage them in system settings. iOS and iPadOS testing uses TestFlight, with installation subject to review and invitation status. We will update the website when a public invitation is available.
